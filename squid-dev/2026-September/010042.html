Hi all,

The history:

In the past the man(8) page ("manuals") for Squid have their COPYRIGHT 
section created as either a cut-n-paste of all the relevant copyright 
claim and blurbs from the code or prior documentation used to assemble 
the manual. Some have additional author copyrights added during creation 
when the manual was edited or created separately.


During my recent work to update the Squid manual pages translation
Alex requested we improve the look of these "COPYRIGHT" section.


So:

Here is my proposal for changes to the Squid Project documentation 
guidelines which need to be updated (and then complied with)
<https://github.com/squid-cache/squid-cache.github.io/pull/52>


Most importantly there would be no changes to any copyright claim, nor 
wording of the license texts. Though the later would remain able to be 
translated, in fact more easily since code-specific "*", "#" or 
indentation will no longer clutter the translation POT/PO details.


Cheers
