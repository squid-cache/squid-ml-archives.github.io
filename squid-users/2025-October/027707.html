On 2025-10-31 08:12, Dieter Bloms wrote:

 > Does anybody know, howto set the SSL Option SSL_OP_IGNORE_UNEXPECTED_EOF

Squid does not recognize that option by name[^1]. Use option's hex value 
as a workaround until [^1]. If my math is correct[^2], that option hex 
value is 0x80.

[^1]: A quality pull request adding by-name support for all known 
OpenSSL v3.5 options is welcome.

[^2]: From OpenSSL include/openssl/ssl.h.in sources:
#define SSL_OP_BIT(n)  ((uint64_t)1 << (uint64_t)n)
#define SSL_OP_IGNORE_UNEXPECTED_EOF  SSL_OP_BIT(7)


HTH,
