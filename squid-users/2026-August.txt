Web Safety 9.8 - web filter and secure web gateway for Linux is now released. The following changes are included into this version:


  *   The virtual appliance is now based on Ubuntu 26.04 LTS.
  *   Admin UI runs on nginx and gunicorn instead of Apache as in all previous versions.
  *   Virtual appliance includes latest version of Squid 7.6 for Ubuntu 26.04 with repository hosted on GitHub<https://github.com/diladele/repo-squid-7_6_2-ubuntu-26_04>.
  *   Added ability to easily manage FTP and SSH CONNECT tunnels<https://www.diladele.com/websafety/docs/faq/squid/network/allow_ssh_or_ftp_connection_through_squid_proxy/#allow-ssh-connections-through-squid> in Admin UI.
  *   Added ability to automatically categorize the unknown domains using OpenAI<https://www.diladele.com/websafety/docs/web_filter/ai_categorization/> artificial intelligence models.
  *   Rewritten module responsible for timezone configuration on the virtual appliance.
  *   Added file system usage section in Admin UI / Dashboard / ICAP server tab.

The virtual appliance images can be downloaded from here:

  *   for VMware ESXi/vSphere<https://www.diladele.com/pkg/websafety-va/9.8/websafety.zip>
  *   for Microsoft Hyper-V<https://www.diladele.com/pkg/websafety-va/9.8/websafety-hyperv.zip>
  *   for Proxmox VE<https://www.diladele.com/pkg/websafety-va/9.8/websafety-proxmox.zip>

Upgrade steps are described in the Admin Guide<https://www.diladele.com/websafety/docs/install/upgrade/>, but ideally you would just deploy a new virtual appliance and import settings from the old one.
As always list of open issues is available on GitHub<https://github.com/diladele/websafety/issues>. Please do not hesitate to add more if something is missing or needs to be improved.

New Web Safety is now available with a free business license for up to 7 users<https://www.diladele.com/websafety/licensing.html>. If you know organizations looking for a self hosted comprehensive web filtering solution for a small environment, please let them know about this option. If you like the application, please also share it with your fellow IT administrators to help us spread the word.

Best regards,
