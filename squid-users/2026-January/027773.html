On Tue, Jan 20, 2026 at 9:33 AM Rafael Akchurin <
rafael.akchurin at diladele.com> wrote:

> Good morning everyone,
>
>
>
> Web Safety 9.7 <https://www.diladele.com/websafety/index.html> – ICAP web
> filter and Admin UI for Squid is now released. The following changes are
> included into this version:
>
>
>
>    - The virtual appliance includes latest version of Squid 7.2 with repository
>    hosted on GitHub
>    <https://github.com/diladele/repo-squid-7_2_2-ubuntu-24_04>.
>    - Site categorization database
>    <https://github.com/diladele/categories-db> is now hosted on GitHub.
>    - Site categorization module is rewritten to include some more
>    categories. Several categories are consolidated and partially retired.
>    - IWF categorization database is now hosted on GitHub.
>    - It is now possible to quickly disable all web filtering in a given
>    policy without disabling each rule. This setting can be adjusted in the
>    Advanced section of a web filtering policy.
>    - Fixed lack of traffic records in Traffic Monitor/ Realtime activity
>    which occurred after midnight in any UTC minus time zone.
>    - It is now possible to block domains by their IP address/range and
>    subnet in the web filtering policies.
>
>
>
> The virtual appliance images can be downloaded from here:
> • for VMware ESXi/vSphere
> <https://packages.diladele.com/websafety-va/9.7/websafety.zip>
> • for Microsoft Hyper-V
> <https://packages.diladele.com/websafety-va/9.7/websafety-hyperv.zip>
> • for Proxmox VE
> <https://packages.diladele.com/websafety-va/9.7/websafety-proxmox.zip>
>
>
>
> Upgrade steps required are described in the Admin Guide
> <https://www.diladele.com/websafety/docs/install/upgrade/>, but ideally
> you would just deploy a new virtual appliance and import settings from the
> old one.
>
> As always list of open issues
> <https://github.com/diladele/websafety/milestones> is available on
> GitHub. Please do not hesitate to add more if something is missing or needs
> to be improved.
>
>
>
> Also note, you can now use Web Safety for your home experiments completely
> free, the license key can be downloaded from here
> <https://www.diladele.com/websafety/licensing.html>.
>
>
>
> Hope you will find this useful.
>
> Best regards,
> Rafael
>
