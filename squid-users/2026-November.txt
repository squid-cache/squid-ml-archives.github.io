Hello everyone,

Following the recent official release of Squid 7.8 we also have build Squid for Windows using CygWin. This can be directly downloaded from https://www.diladele.com/squid/download.html . The repository for the project https://github.com/diladele/squid-windows  was also updated, the steps to build it yourself if you wish are directly in the readme.

The direct download link is https://www.diladele.com/pkg/squid/7.8/squid-7.8_amd64.msi
Older version 7.7 will remain at https://www.diladele.com/pkg/squid/7.7/squid-7.7_amd64.msi

If something does not work correctly in the installer, please use discussion at https://github.com/diladele/squid-windows/discussions or create a new issue in the repo.
For all errors related to functionality of Squid itself continue using this mailing group.

Hope you will find this useful.

Best regards,
Rafael
