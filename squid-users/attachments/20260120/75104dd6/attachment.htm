<p class="MsoNormal"><span style="font-size:11.0pt">Good morning everyone,<o:p></o:p></span></p>
<p class="MsoNormal"><span style="font-size:11.0pt"><o:p> </o:p></span></p>
<p class="MsoNormal"><span style="font-size:11.0pt"><a href="https://www.diladele.com/websafety/index.html">Web Safety 9.7</a> – ICAP web filter and Admin UI for Squid is now released. The following changes are included into this version:<o:p></o:p></span></p>
<p class="MsoNormal"><span style="font-size:11.0pt"><o:p> </o:p></span></p>
<ul style="margin-top:0in" type="disc">
<li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">The virtual appliance includes latest version of Squid 7.2 with
<a href="https://github.com/diladele/repo-squid-7_2_2-ubuntu-24_04">repository hosted on GitHub</a>.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">Site
<a href="https://github.com/diladele/categories-db">categorization database</a> is now hosted on GitHub.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">Site categorization module is rewritten to include some more categories. Several categories are consolidated and partially retired.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">IWF categorization database is now hosted on GitHub.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">It is now possible to quickly disable all web filtering in a given policy without disabling each rule. This setting can be adjusted in the Advanced section of a web filtering
 policy.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">Fixed lack of traffic records in Traffic Monitor/ Realtime activity which occurred after midnight in any UTC minus time zone.<o:p></o:p></span></li><li class="MsoNormal" style="mso-list:l0 level1 lfo1"><span style="font-size:11.0pt">It is now possible to block domains by their IP address/range and subnet in the web filtering policies.<o:p></o:p></span></li></ul>
